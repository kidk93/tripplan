# 학생용 V2.0 웹앱

학생용 접속: https://kidk93.github.io/tripplan/

## 올릴 파일

배포 ZIP을 풀고 그 안의 파일을 학생용 저장소 최상위에 올립니다.
`index.html`, `sw.js`, `manifest.webmanifest`, `icon.svg`, PNG 아이콘 3개, `LICENSES.txt`, 이 안내와 숨김 파일이 들어 있습니다.

**학생·교사 저장 자료, 명단, 시험용 자료는 올리지 않습니다.** 이 묶음에는 포함하지 않았습니다.

## GitHub Pages 설정

1. 학생용 저장소에 ZIP 안의 파일을 업로드합니다. ZIP 자체를 올리는 방식이 아닙니다.
2. 저장소 Settings → Pages → Source: Deploy from a branch.
3. Branch: main / 폴더: /(root) → Save.
4. GitHub가 표시하는 HTTPS 주소를 열어 확인한 뒤 학생에게 전달합니다.

GitHub 공식 안내: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 학생 사용 순서

1. Safari 또는 Chrome에서 주소를 열고 홈 화면 앱으로 추가하거나 HTML 파일을 내려받습니다. 일반 웹브라우저에서는 계획 작성을 시작하지 않습니다.
2. 홈 화면 아이콘 또는 내려받은 HTML을 열기 → 학생 정보·4자리 암호 입력 → 계획 작성 → 선생님께 계획 보내기.
3. 교사 검토 결과 반영 → 신청서 작성 → 보고서 작성.
4. 첫 화면의 홈 화면에 추가 버튼을 누릅니다. 아이폰은 안내에 따라 공유 → 홈 화면에 추가 → 추가를 누릅니다. 지원 브라우저는 앱 설치 확인 창을 엽니다.
5. 기기 변경 전 내 자료 → 내 자료 저장. 새 기기에서 저장한 내 자료 불러오기.

홈 화면 추가만으로 자료 보존을 보장하지는 않습니다. 브라우저 자료 삭제 전에는 백업합니다.
기기 보관은 암호화되며, 학생 자료를 GitHub로 자동 전송하지 않습니다.

## 학교 기준

기본값은 백운고 2026학년도 기준입니다.
다른 학교·연도로 사용할 경우 교사용 설정을 먼저 확인합니다.

- HTML 배포: 교사용 학생 배포 → 학생용 HTML 저장. 학교 기준이 내장됩니다.
- 웹앱 배포: 교사용 설정 → 학생 웹앱 기준 전달 → 웹앱용 학교 기준 저장.
- 학생: 내 자료 → 학교 기준 가져오기에서 받은 .tripsettings 파일 선택.

## 버전 교체

1. 학생은 내 자료 저장으로 백업합니다.
2. 배포 ZIP의 파일을 같은 저장소·같은 경로에 교체합니다.
3. 기존 앱 창을 모두 닫고 다시 엽니다. 새 서비스 워커는 기존 창이 닫힌 후 적용됩니다.
4. 저장소·주소를 바꾸면 기존 브라우저 보관 자료가 자동 이동하지 않습니다. 백업 파일을 불러옵니다.

## 실제 주소에서 마지막 확인

- 아이폰 Safari·아이패드·컴퓨터에서 계획 작성과 교사 결과 반영.
- 홈 화면 추가 후 재실행, 최초 온라인 접속 후 오프라인 재실행.
- PDF·쪽별 PNG 저장, 복사·붙여넣기, 백업·복원.

오프라인 준비 완료는 앱에 필요한 파일을 기기에서 모두 확인한 경우에만 표시합니다. 아이폰·아이패드의 실제 설치와 비행기 모드 재실행도 확인해 주세요.

웹브라우저에서 이전에 작성한 자료는 첫 화면의 이전에 작성한 자료 백업으로 보관한 뒤, 홈 화면 앱이나 HTML의 저장한 내 자료 불러오기에서 옮깁니다. 설치 여부와 관계없이 학생 자료를 GitHub에 자동 전송하지 않습니다.
